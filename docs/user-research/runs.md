# User research runs

Research public complaints and workarounds to understand where Newsworthy helps
and what should change. These are qualitative samples, not market prevalence
estimates or an approved roadmap. The [opportunity ledger](opportunities.md)
tracks product decisions separately from this append-only research history.

Run the repository skill with `$newsworthy-user-research`, or ask an agent to
read [the skill](../../.agents/skills/newsworthy-user-research/SKILL.md) and conduct
a run. Each run records exact searches, source evidence, limitations and lessons
to improve the next one. There is no automatic schedule or outreach.
