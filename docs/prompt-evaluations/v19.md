# v19: the sentence never names a news outlet

On 2026-09-27 the owner set a convention: the sentence never shows the name of
a news outlet. It is also rule 8 in `PROMPT-RULES.md`, so every later version
has to keep it.

Shipped text: version 19, hash `66043069a1277b7e`, 2,298 characters (limit
2,300).

## Why

v17's Style line says "Claims: said." The caller took that as an instruction
to attribute reports to the outlet that carried them. In the last 90 days of
production history, 790 stored sentences, twelve name an outlet. Ten are from
v17 on 2026-09-26, each ending "the Wall Street Journal said" or "the Wall
Street Journal reported" (readings 766 to 782). One from 2026-09-25 ends
"Reuters said" (745). One more (676, v13) names CNN, MS Now and Politico
because the story itself was about them being barred from the White House.
The owner's rule is "ever", so v19 covers that case too.

## What changed from v18

One Style entry. Everything else, Scale and Examples included, is v18's
verbatim, so v18 and v19 readings measure the same thing.

- v18: `Claims: said.`
- v19: `Claims: said or reportedly. Never name news outlets.`

"Reportedly" gives the rater a way to keep the attribution of an unconfirmed
report without naming who carried it. Dropping the attribution would state a
report as fact. Naming the people a report cites ("US officials said") is
still allowed.

## How it was tested

got only the full prompt text and the same five source notes, with no web
access, and wrote one JSON reading per note. These are not production runs:
no search, no judging, nothing submitted. The notes are reconstructed from
stored readings and are fixtures, not verified reporting.

- A: WSJ report that Trump rejected Iran's Hormuz plan (readings 766 to 782).
- B: Reuters report of early US-Iran talks (745).
- C: the White House barring CNN, MS Now and Politico (676).
- D: Saudi Arabia's own statement on an intercepted missile (639), a control
  where the source is a government, not an outlet.
- E: a Bloomberg report of Japanese yen intervention (invented fixture).

## Findings

- **Outlet names:** v18 named one in 3 of 10 sentences, all from one run
  (Reuters, Bloomberg, and CNN, MS Now and Politico). v19 named one in 0 of 15.
- **Attribution kept:** v19 used "reportedly" for every outlet-sourced report
  (A, B and E in all three runs) and never stated those reports as fact.
  Note C became "three news outlets" or "some reporters".
- **Control:** D kept "Saudi Arabia said" in every run of both versions, so the
  rule did not strip attribution to governments or officials.
- **Length:** all 25 sentences were within the 135-character body limit.
- **Scores:** v19 scored A and B a point higher in some runs (6 and 5 against
  v18's 5 and 4). Five runs on fixtures can't tell that apart from noise, and
  nothing is claimed about calibration.

## Limits

Two v18 runs and three v19 runs are a small sample. Nothing here tests the
live search workflow, the production caller, or how often a real run meets an
outlet-attributed story. Adoption is established only by a verified v19
reading arriving in production. No server-side check was added: the four
rejection rules stay four, and a stored sentence is not rewritten.
