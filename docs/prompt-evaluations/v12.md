# v12 sentence-writing evaluation

Tested 19 September 2026; published as v12 on 20 September 2026.
The user's preferred sentence was 150 characters including spaces and
punctuation. This replaces the previous 25-word generation instruction.

## Method and limits

72 actual generations: six source cards, three fresh invocations per variant,
and four variants. Each invocation generated six sentences. All variants used
identical notes and a neutral wrapper. The configured model was GPT-6 Astra at
high effort, through the Codex CLI. Only the sentence-writing instructions were
tested, not score selection, the complete prompt, web search or submission.
No generated output was repaired, truncated or discarded.

The notes were reconstructed from saved readings, not independently verified
reporting. Added uncertainty notes were shared across all variants. These are
writing fixtures, not new calibration examples. The fourth variant was an
exploratory revision after the first proposal dropped useful details and
expanded NATO unnecessarily. Manual assessments were by the prompt author, not
an independent blind judge. The revised variant reused these six cases, so this
is a small exploratory test, not a held-out benchmark or production-Claude
validation.

[Exact instructions, wrapper, source cards, rubric and all outputs](v12.json)
are retained together. The final `published_prompt_text` is the complete v12
prompt; `design.arms.revised` is the sentence-writing portion actually exercised.

## Results

| Variant | Within 150 characters | Semicolons | Em dashes |
|---|---:|---:|---:|
| Current v11 writing instructions | 17/18 | 1 | 0 |
| Change the limit only | 18/18 | 1 | 0 |
| First style proposal | 18/18 | 0 | 0 |
| Revised style proposal, selected for v12 | 18/18 | 0 | 0 |

The revised outputs were 74–121 characters. All counts include spaces and
punctuation. All invocations returned the six expected case IDs.

- All three current and limit-only Greenland sentences retained the vague
  ending “changing Arctic basing arrangements.” Both style variants omitted it.
- The first style proposal omitted China and India from all three sanctions
  sentences even though they fit. The revision retained both names in all three
  outputs and still described tariffs as authorized, not imposed.
- The first proposal expanded NATO in all three Poland sentences. The revision
  retained NATO and replaced “deniable strikes” with a plain explanation.
- Both style variants focused the oil sentence on the repair plan and preserved
  its future tense, instead of appending market shorthand.
- The tanker sentences were already clear across variants; there is no measured
  improvement on that case. The rates outputs still varied in which useful
  detail survived and sometimes retained “benchmark rate.”
- Manual review found no clear violation of the case-specific critical checks.
  That establishes fidelity only to the supplied notes, not to external news.

## Implementation boundary

Only Output changes between v11 and v12. All prior prompt bytes, the scale,
calibration examples and digest provenance contract are preserved. The caller
reference and OpenAPI now describe 150 characters. This is generation guidance;
the API's existing 400-character truncation and four rejection rules remain.

Deployment and a later verified v12 reading establish delivery and caller
adoption separately. This evaluation does not claim either or native visual
verification.
